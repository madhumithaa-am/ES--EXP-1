# POTENTIOMETER-BASED WATER LEVEL DETECTION USING ARDUINO UNO

## Aim

To design and implement a potentiometer-based water level detection system using Arduino UNO and four LEDs to indicate different water levels such as Empty, Low, Half Full, and Full.

---

# Hardware / Software Tools Required

* Arduino UNO
* Potentiometer
* Red LED
* Orange LED
* Yellow LED
* Green LED
* 220Ω / 330Ω Resistors
* Breadboard
* Jumper Wires
* USB Cable
* Arduino IDE / Tinkercad Circuits

---

# Circuit Diagram

The circuit consists of an Arduino UNO, a potentiometer, four LEDs, and current-limiting resistors.

The potentiometer is connected to the analog input A0 of the Arduino UNO. The four LEDs are connected to digital pins D10, D11, D12, and D13.

The LEDs indicate the water level as follows:

* Red LED → Empty
* Orange LED → Low
* Yellow LED → Half Full
* Green LED → Full

---

# Water Level Detection System

The system works by reading the analog value generated by the potentiometer.

The potentiometer produces an analog value between 0 and 1023. Arduino UNO reads this value through analog pin A0 and compares it with predefined threshold values.

```text
Potentiometer
      ↓
Analog Input A0
      ↓
Arduino UNO
      ↓
Read Analog Value
      ↓
Compare with Threshold
      ↓
Water Level Identification
      ↓
LED Indication

### KEIL 

```py
#include <lpc17xx.h> 
#include "delay.h" //User defined library which conatins the delay routines 
#include "gpio.h" 
#define LED P1_29 // Led is connected to P1.29 
/* start the main program */ 
int main() 
{ 
  SystemInit(); //Clock and PLL configuration 
  GPIO_PinFunction(LED,PINSEL_FUNC_0); // Configure Pin for Gpio 
  GPIO_PinDirection(LED,OUTPUT); // Configure the pin as OUTPUT 
  GPIO_PinWrite(LED,LOW); 
  while(1) 
 { 
   /* Turn On all the leds and wait for 100ms */ 
   GPIO_PinWrite(LED,HIGH); // Make all the Port pin as high 
   DELAY_ms(100); 
 
   GPIO_PinWrite(LED,LOW); // Make all the Port pin as low 
   DELAY_ms(100); 
  } 
}
```
